Chapter 3: Algebraic Fractions

“An algebraic fraction is just a fraction wearing a variable disguise. Peel it back, and the same rules apply.”

— Professor’s Notebook

You’ve simplified \(\frac{12}{18}\), added \(\frac{2}{3} + \frac{5}{6}\), and divided \(\frac{3}{4} \div \frac{1}{2}\). Now, we do the same—but with expressions like \(\frac{x}{2}\), \(\frac{3a}{a+1}\), or \(\frac{x^2 - 4}{x - 2}\). These appear everywhere: in rates, proportions, formulas, and later, in calculus.

This chapter teaches you to simplify, combine, and compute with algebraic fractions confidently—by recognizing structure, factoring, and applying familiar fraction rules.

3.1 Review of Fraction Operations (with Variables)

The core rules do not change—only the ingredients.

Operation Rule
Multiplication \(\frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd}\)
Division \(\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \cdot \frac{d}{c}\)
Addition/Subtraction Requires common denominator: \(\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}\)

Critical reminder:
You can only cancel factors that are multiplied, not added.
✅ \(\frac{3x}{6} = \frac{x}{2}\) (cancel 3)
❌ \(\frac{x + 3}{x + 6} \ne \frac{3}{6}\) — never cancel across addition!

3.2 Simplifying Algebraic Fractions

To simplify, factor numerator and denominator, then cancel common factors.

Step-by-Step Process

  1. Factor everything completely.
  2. Cancel any common factors (not terms!).
  3. State any restrictions (values that make denominator zero).

Example 1: Simplify \(\frac{6x^2}{9x}\)

  • Factor: \(\frac{2 \cdot 3 \cdot x \cdot x}{3 \cdot 3 \cdot x}\)
  • Cancel common factors (3 and one \(x\)): \(\frac{2x}{3}\)
  • Restriction: \(x \ne 0\) (since original denominator = 0 when \(x = 0\))

Example 2: Simplify \(\frac{x^2 - 9}{x + 3}\)

  • Numerator is a difference of squares: \(x^2 - 9 = (x - 3)(x + 3)\)
  • So: \(\frac{(x - 3)(x + 3)}{x + 3}\)
  • Cancel \((x + 3)\): Result = \(x - 3\)
  • Restriction: \(x \ne -3\)

Why restrictions matter:
The original expression is undefined at \(x = -3\), even though the simplified form \(x - 3\) is defined there. They are equal only where both exist.

Example 3: Simplify \(\frac{2x + 4}{x^2 + 3x + 2}\)

  • Factor numerator: \(2(x + 2)\)
  • Factor denominator: \((x + 1)(x + 2)\)
  • Cancel \((x + 2)\): \(\frac{2}{x + 1}\)
  • Restrictions: \(x \ne -1,\ -2\)

3.3 Finding Common Denominators

To add or subtract algebraic fractions, you need a common denominator—preferably the Least Common Denominator (LCD).

How to Find the LCD

  1. Factor all denominators completely.
  2. Take the highest power of each distinct factor.

Example:

\[ \frac{3}{x(x + 2)} \quad \text{and} \quad \frac{5}{(x + 2)^2} \]
  • Factors: \(x,\ (x + 2),\ (x + 2)^2\)
  • LCD = \(x(x + 2)^2\)

Tip:
If denominators share no common factors, LCD = product of denominators.

3.4 Operations with Algebraic Fractions

Addition & Subtraction

Example:

\[ \frac{2}{x} + \frac{3}{x + 1} \]
  1. LCD = \(x(x + 1)\)
  2. Rewrite each fraction:
    \[ \frac{2(x + 1)}{x(x + 1)} + \frac{3x}{x(x + 1)} = \frac{2x + 2 + 3x}{x(x + 1)} = \frac{5x + 2}{x(x + 1)} \]

Example (with factoring):

\[ \frac{1}{x - 2} - \frac{1}{x^2 - 4} \]
  • Note: \(x^2 - 4 = (x - 2)(x + 2)\)
  • LCD = \((x - 2)(x + 2)\)
  • Rewrite:
    \[ \frac{(x + 2)}{(x - 2)(x + 2)} - \frac{1}{(x - 2)(x + 2)} = \frac{x + 2 - 1}{(x - 2)(x + 2)} = \frac{x + 1}{(x - 2)(x + 2)} \]

Multiplication

Example:

\[ \frac{x + 3}{2x} \cdot \frac{4x^2}{x^2 - 9} \]
  1. Factor: \(x^2 - 9 = (x - 3)(x + 3)\)
  2. Write all factors:
    \[ \frac{(x + 3)}{2x} \cdot \frac{4x^2}{(x - 3)(x + 3)} \]
  3. Cancel:
    • \((x + 3)\) cancels
    • \(x\) cancels one \(x\) in \(x^2\)
    • 4 and 2 → 2 remains
  4. Result: \(\frac{2x}{x - 3}\)
  5. Restrictions: \(x \ne 0,\ 3,\ -3\)

Division

Example:

\[ \frac{x^2 - 1}{x + 2} \div \frac{x - 1}{3x} \]
  1. “Keep, Change, Flip”:
    \[ \frac{x^2 - 1}{x + 2} \cdot \frac{3x}{x - 1} \]
  2. Factor: \(x^2 - 1 = (x - 1)(x + 1)\)
  3. Cancel \((x - 1)\):
    \[ \frac{(x + 1)}{x + 2} \cdot 3x = \frac{3x(x + 1)}{x + 2} \]
  4. Restrictions: \(x \ne -2,\ 1,\ 0\)

Chapter Summary

  • Algebraic fractions follow the same rules as numerical fractions—but require factoring.
  • Simplify by factoring and canceling common factors (never terms!).
  • LCD is built from the highest powers of all denominator factors.
  • Always state restrictions: values that make any original denominator zero.
  • Operations:
    • Multiply/Divide: factor, cancel, simplify
    • Add/Subtract: find LCD, rewrite, combine numerators

Practice Problems

  3. Add: \(\frac{3}{x} + \frac{2}{x + 1}\)
  4. Subtract: \(\frac{5}{x - 1} - \frac{2}{x^2 - 1}\)
  5. Multiply: \(\frac{x + 4}{x^2 - 16} \cdot \frac{2x}{x + 4}\)
  6. Divide: \(\frac{x^2 - 9}{x} \div \frac{x + 3}{2x^2}\)
  7. State all restrictions for problem #6.
