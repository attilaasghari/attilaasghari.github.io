Welcome to My Digital Workspace

I began my computer journey when I got my first computer at age 6. At first, my main interest was hardware, and I earned my PC Repairman certificate from TVTO (Technical & Vocational Training Organization) at age 15. About This Website

this website is my piece of web, I share a lot of thing here my technical documents, project, software, books, hobbies, papers, images, ... so I keep the style of this website simple and without graphics to prevent it from becoming heavy and I want the main focus to be on the content not the UI of the website.

How I Maintain: I built and maintain this website using LibreOffice. The reason is that I don't have enough time to write HTML, and I don't like CMSs like WordPress or other static site generators because they're heavy or have options I really don't need. So after searching a lot for the easiest way to keep maintaining my website, I came up with the idea of using a Word-like environment to update it easily. And since I use Ubuntu as my main OS, I chose LibreOffice.
