Academic & Educational

  • Disk Scheduling Algorithms Simulator

A comprehensive desktop application built with Python that demonstrates six disk scheduling algorithms: FCFS, SSTF, SCAN, C-SCAN, LOOK, and C-LOOK. Features interactive visualization with Matplotlib, performance metrics, and binary releases for Windows. Perfect for operating systems courses and algorithm comparison.

  • Disk Scheduling Algorithms Simulator – (web version)

A web-based educational tool for demonstrating and comparing disk scheduling algorithms used in operating systems. This simulator implements all major disk scheduling algorithms.

  • Signal & Systems Simulator

A comprehensive, interactive educational tool for computer engineering and electronic engineering students studying Signals and Systems. Visualize signals, analyze LTI systems, and explore transforms in both time and frequency domains.

  • Sorting Algorithms Simulator

A professional desktop application built with Python and PyQt6, visualizing all major and advanced sorting algorithms. Features interactive step-by-step visualization, real-time performance metrics, and educational explanations. Perfect for students and educators exploring algorithm behavior.



Research

Software that built based on research papers or useful tools for researches

  • Heart Rate Fragmentation Analyzer

A research-grade Python desktop application faithfully re-implementing the original Heart Rate Fragmentation (HRF) algorithm from PhysioNet's reference AWK code. This software analyzes ECG R-peak time series to quantify short-term cardiac rhythm fragmentation, providing an intuitive graphical interface, batch processing, customizable parameters, and data visualization.

Based on: PhysioNet Heart Rate Fragmentation Code (AWK)
